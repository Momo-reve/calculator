# calculator
Calculatrice responsive developpée en TypeScript, HTML et CSS

## Technologies utilisées :

- HTML5
- CSS 3 (Grid, animations)
- TypeScript
- Tailwind CSS

## Fonctionnalités : 

- Opérations de base : addition, soustraction, division, multiplication et gestion du pourcentage
- Suppression de caractère par caractère (DEL) et remise à zéro (AC)
- Respect des priorités opératoires (x et / avant + et -)
- Gestion des erreurs (division par zéro)
- Affichage de l'historique du calcul en cours

## Structure du projet 
```
calculator/
    css/
        style.css
    JS/
        script.js
        script.ts
    index.html
```
## Lancer le projet

Clonez le repo puis ouvrez `index.html` dans votre navigateur
```bash
git clone https://github.com/Momo-reve/calculator 
```
